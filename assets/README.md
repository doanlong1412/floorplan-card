# assets/

Thư mục này chứa ảnh minh hoạ được tham chiếu trong README.md / README_en.md.

Cần thêm 2 ảnh sau trước khi publish (README hiện đang trỏ tới các đường dẫn này):

- `preview.png` — ảnh chụp màn hình card khi hiển thị bình thường trên dashboard
  (ví dụ: sơ đồ nhà với nhãn phòng, cổng, thanh trạng thái đang hiển thị)
- `editor-preview.png` — ảnh chụp màn hình trình chỉnh sửa trực quan (Config Editor),
  có thể chụp thêm màn hình "chỉnh vị trí kéo-thả" nếu muốn minh hoạ rõ hơn

Chỉ cần đặt đúng tên file và đúng thư mục này, không cần sửa gì thêm trong README.

> File này (`assets/README.md`) chỉ là ghi chú tạm thời — có thể xoá sau khi đã thêm đủ ảnh thật.
